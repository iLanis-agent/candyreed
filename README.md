# Candyreed 1.0 TEST
Native Java/Canvas Android 8+ Lollipops circle-and-stick pairing puzzle.

Place circles and horizontal or vertical sticks in some cells. Every circle needs exactly one edge-adjacent stick pointing toward it, and every stick needs exactly one circle. Each lollipop is a two-cell pair; separate pairs may meet at corners but never share an edge. In every row and column, skip empty cells: consecutive nonempty symbols must have different types. Circle, horizontal stick and vertical stick are three different types. Gold given symbols stay fixed. Tap an editable tile to cycle empty, circle, horizontal stick, vertical stick, empty. Twelve distinct 3x3 given boards have twelve distinct unique solutions.

Saved candy palette and cell guides, GG007 icon/menu/site/privacy, unlimited undo/reset. Offline, no ads, analytics, account or requested permissions. Settings and completed-puzzle marks stay on device. External studio link opens browser.

Independent Java coordinate-set occupied components must contain exactly a circle and one correctly aligned stick; filtered row/column type lists must alternate. This agrees with production local partner-degree checks and directional nearest-symbol scans on all 262144 four-state boards per puzzle. Exactly one solution per board; givens, bounds, cycling, solve, undo and replay pass. Adapter navigation, saved settings, privacy, cell taps, next, levels and persistence pass. Actual drawing pixels inspected, not phone screenshots. Phone runtime, performance and browser handoff QA incomplete. Signed TEST only, not final or Play published.

Current 803-entry registry, 129 partial recovered README records and exact Gapcedar cumulative stage found no Lollipops or circle-and-stick match. Unlike Twinmarsh/Norinori binary dark dominoes with room quotas, each pair here has typed oriented head/stick roles, and same symbols cannot consecutively see each other through empty cells. Unlike Magnetmere there is no fixed pair tiling, polarity or row/column pole quotas. Unlike Gapcedar/Hanare this uses symbol alternation and aligned isolated pairs rather than numeric differences. Nuribou was rejected as Barrowisle, Canal View as an existing game, and Heyablock as an existing room-block game. Known Lollipops genre, not a global invention. Partial corpus, not ALL-local.
